# Grupo Cardan — Sitio web listo para GitHub Pages

Este paquete ya está preparado para publicarse como sitio estático en GitHub Pages.

## Publicar gratis
1. Crea una cuenta en GitHub si todavía no tienes una.
2. Crea un repositorio nuevo, por ejemplo: `grupo-cardan`.
3. Sube **todo el contenido de esta carpeta** a la raíz del repositorio. `index.html` debe quedar en la raíz.
4. En GitHub abre: **Settings → Pages**.
5. En **Build and deployment**, selecciona **Deploy from a branch**.
6. Selecciona la rama **main** y la carpeta **/(root)**, y guarda.
7. GitHub mostrará la dirección pública del sitio después de unos minutos.

## Cambiar WhatsApp, correo o ubicación
Edita únicamente el archivo `site-config.js`.

## Cambiar textos, servicios o proyectos
Edita `index.html` desde GitHub usando el ícono de lápiz. No necesitas instalar programas.

## Cambiar fotografías
Reemplaza las imágenes dentro de `assets/images/` conservando el mismo nombre, o actualiza la ruta correspondiente en `index.html`.

## Dominio propio más adelante
Puedes conectar un dominio comprado después sin rehacer la web. GitHub Pages admite dominios personalizados desde Settings → Pages.
